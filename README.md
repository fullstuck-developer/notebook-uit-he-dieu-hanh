# Sổ tay Hệ điều hành (Operating Systems Notebook)

Chào mừng đến với sổ tay học tập môn Hệ điều hành. Thư mục này lưu trữ các tài liệu, bài giảng và ghi chú liên quan đến môn học.

## Cấu trúc dự án

- `NoiDungHoc/`: Chứa nội dung học tập.
  - `BaiGiang/`: Các tệp PDF slide bài giảng môn học.
  - `BaiGiang.md/`: Các tệp ghi chú Markdown cho từng chương (Ví dụ: Chapter 5, Chapter 7, Chapter 8).
  - `mindmap.html`: Sơ đồ tư duy tổng hợp kiến thức môn Hệ điều hành.

## Mục tiêu

- Ghi chú và tóm tắt kiến thức môn Hệ điều hành.
- Lưu trữ tài liệu học tập một cách có hệ thống.
